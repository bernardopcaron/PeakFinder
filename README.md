# PeakFinder

Plataforma de mapeamento e planejamento de escaladas no Brasil.

## Desenvolvimento

```bash
cp .env.example .env.local   # preencha as chaves do Supabase
npm install
npm run dev
```

## Testes

```bash
npm test          # unitários e de banco (Vitest)
npm run test:e2e  # ponta a ponta (Playwright)
```
